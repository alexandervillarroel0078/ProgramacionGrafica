# Capturas de la entrega

Guardá aquí las capturas que muestra la sección 10 de `ENTREGA.md`:

| Archivo | Qué mostrar |
|---|---|
| `dia.png` | Cámara de seguimiento de día, con edificios, toldos, tráfico y HUD |
| `noche.png` | La misma zona de noche (tecla N), con farolas, ventanas encendidas y luces del tráfico |
| `minimapa.png` | Minimapa con sectores, auto y destino (puede ser un recorte de la esquina superior derecha) |
| `parque.png` | Un parque con fuente, senderos, árboles y bancos |

En Windows, **Win + Shift + S** recorta una zona de la pantalla; después se pega en Paint y se guarda como PNG con el nombre indicado.
